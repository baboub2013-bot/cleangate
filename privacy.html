CleanGate Privacy Policy

Last updated: July 13, 2026

1. Overview

CleanGate is a Discord verification and moderation bot. This Privacy Policy explains what data CleanGate may collect, how it is used, and how it is protected.

2. Data CleanGate May Collect

Depending on server configuration and user interaction, CleanGate may process:

  • Discord user ID;
  • Discord username, display name, and avatar;
  • Discord server ID where CleanGate is installed;
  • role IDs and channel IDs required for configuration;
  • moderation review status, reasons, timestamps, and related log message IDs;
  • OAuth2 verification data, including the list of guild IDs returned by Discord during verification.

3. OAuth2 Data

CleanGate may request Discord OAuth2 scopes such as identify and guilds. The guilds scope is used to compare a user’s server membership against the configured CleanGate blacklist. CleanGate does not publicly expose the user’s full server list.

4. How Data Is Used

CleanGate uses data to:

  • verify users;
  • assign verification or review roles;
  • create moderation review cases;
  • send moderation logs;
  • apply configured moderation actions;
  • store server-specific CleanGate configuration.

5. Data Storage

CleanGate may store configuration data and review data needed for the bot to function. CleanGate does not sell user data.

6. Data Sharing

CleanGate does not sell or share personal data with advertisers. Data may be visible to authorized server staff through moderation logs and review channels.

7. Data Retention

Data is kept only as long as necessary for CleanGate to provide verification and moderation features. Server owners may remove CleanGate from their server or request removal of stored server configuration where applicable.

8. Security

Reasonable measures are used to protect CleanGate data. However, no online service can guarantee complete security. Server owners should keep bot tokens, client secrets, and environment variables private.

9. User Rights

Users may contact the CleanGate developer to request information about stored data or request deletion where applicable.

10. Contact

For privacy questions or deletion requests, contact the CleanGate developer through the official support server or application contact method.
